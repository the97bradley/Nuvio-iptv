# Upstream NuvioMedia snapshots

Vendored shallow snapshots of NuvioMedia repositories for hub development.

Refresh with:

```bash
./scripts/sync-upstream.sh
```

TorrServer / libtorrserver binaries are excluded from git; fetch from the original repos if you need them.
